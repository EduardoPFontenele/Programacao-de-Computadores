# Programação I — UFMT

Repositório com exercícios resolvidos da disciplina de **Programação I** do curso de Ciência da Computação da **Universidade Federal de Mato Grosso (UFMT)** — Campus do Araguaia, Barra do Garças/MT.

Os exercícios estão organizados por tópico, acompanhando a progressão dos conteúdos abordados ao longo da disciplina, todos desenvolvidos em **Python**.

## 📚 Conteúdo

O repositório está dividido nas seguintes pastas, organizadas por tema:

| Pasta | Descrição |
|-------|-----------|
| **Conceitos Básicos de Programação** | Entrada e saída de dados, variáveis, tipos primitivos, operadores e expressões. |
| **Estrutura de Seleção** | Estruturas condicionais (`if`, `elif`, `else`) e tomada de decisão. |
| **Estruturas de Repetição** | Laços de repetição (`for`, `while`) e controle de fluxo. |
| **Listas e Tuplas** | Manipulação de listas e tuplas, indexação, fatiamento e métodos. |
| **Conjuntos e Dicionários** | Estruturas `set` e `dict`, operações de conjunto e mapeamento chave-valor. |
| **Funções** | Definição e uso de funções, parâmetros, retorno e escopo de variáveis. |
| **Modularização** | Organização do código em módulos e reaproveitamento. |
| **Biblioteca Collections** | Uso de estruturas especializadas do módulo `collections` (ex.: `Counter`, `deque`, `defaultdict`). |
| **Manipulação de Arquivos** | Leitura e escrita de arquivos (`open`, modos de acesso, `with`). |
| **Tratamento de Exceções** | Tratamento de erros com `try`, `except`, `finally` e `raise`. |
| **Trabalho** | Trabalho/projeto da disciplina. |

## 🛠️ Tecnologias

- **Linguagem:** Python 3

## ▶️ Como executar

Cada arquivo é independente e pode ser executado individualmente. Com o Python 3 instalado:

```bash
# Clone o repositório
git clone https://github.com/EduardoPFontenele/<nome-do-repositorio>.git

# Acesse a pasta do tópico desejado
cd <nome-do-repositorio>/Funções

# Execute o exercício
python nome_do_arquivo.py
```
